# 譜面の編集(本アプリの追加)

DTX 譜面を置く・消す・動かす・選ぶ・テンポと小節を変える画面。DTXMania NX 同梱の DTXCreator(以下 DTXC)と
vid2dtx のプレビュー(以下 V2D)を手本にした、本アプリの追加機能。手本の挙動は
[dtxcreator-edit.md](dtxcreator-edit.md)・[dtxcreator-ui.md](dtxcreator-ui.md)・[dtxcreator-io.md](dtxcreator-io.md)・
[vid2dtx-edit.md](vid2dtx-edit.md)。ここは「作ったものの挙動」と、手本と違えたところ(末尾の一覧)。

コードは `js/edit/`。文書(`dtxdoc.js`)→ モデル(`model.js`)→ 操作(`ops.js`)→ 履歴(`history.js`)→ セッション
(`session.js`。曲パックへの重ね合わせと下書き)→ 画面(`editor.js` / `view.js` / `gestures.js` / `dialogs.js`)。

## 1. 入口と出口

- 曲の一覧の「✎ 譜面を編集」を押してから譜面を選ぶ。演奏画面の ✎(ドラムのとき)は、今の位置・分岐(`#RANDOM` の乱数)・
  ループを持って開く
- ← で曲の一覧へ。確かめずに閉じる(編集は曲パックに重ね、下書きにも書く。ファイルにするのは「保存」)
- 編集の状態(元に戻すの履歴・ペン・表示)は、曲パックを開き直すまで譜面ごとに持つ。別の曲パックを開くとき、
  ファイルにしていない編集があれば確かめる(開けたときに捨てる。開けなかったときは残す)
- テストプレイ(T)は本物の演奏画面で、再生位置の 1 小節前から。やめる(← / Esc / ✎ / 終了)と編集画面の
  止めた位置へ戻る。譜面を読み終える前にやめたら位置とループは変えない

## 2. 座標

- **u**: 4/4 の小節を 1 とする拍に比例した縦の座標。`U[m] = Σ L[k] (k < m)`(L は小節長)。小節 000 の頭が u = 0、
  リードインの小節は u ∈ [-1, 0)。`u(m, tick) = U[m] + L[m] × tick / 384`。BPM を変えてもチップは動かない(時間だけ変わる)
- **tick**: 小節を 384 等分(パーサと同じ。`pos = (m + 1) × 384 + tick`)
- **画面**: 未来が上。再生位置の線は画面の高さの 75 % に固定。`y = headY − (u − uHead) × 400 × zoom`(論理 px)。
  拡大率は 0.25〜5.6 の 10 段。横は演奏画面と同じ 1920 幅の論理座標で、列の絵も演奏画面と同じ
- **配置**: キャンバスが 720 CSS px 以上なら広い配置(BPM レーン・小節番号の欄・レーン)、狭ければ小節番号の欄とレーン
  (BPM は小節番号の欄に ♩ で出す)。拡大率は配置ごとに覚える。タッチの初めは 1/16 のセルが約 24 CSS px になる拡大率。
  狭い配置のタッチでは −/＋ を出さない(2 本指で拡大する。ツールバーにペン / 選択の切り替えを残すため)

### 2.1 ガイドと吸着

- ガイド間隔は 1/4・1/8・1/12・1/16・1/24・1/32・1/48・1/64・フリー。線 k は小節の頭から k/d(4/4 の小節を 1 とする)の位置で、
  tick は `floor(384 k / (d L))`。小節長が 1 でないときも音楽の拍に合う(3/4 の 1/16 は 32 tick 刻み)
- 吸着はいちばん近い線(同点は後ろ)。小節の終わりの短いセルは次の小節の頭に寄る。フリーは tick の四捨五入。
  (変更) DTXC は下へ切り捨てる(チップの中心が押した位置に来ないため)
- 1 ガイド進める・戻す(↑↓・塗り)は、線の tick が割り切れない小節でも必ず次の線へ進む

## 3. 列とチップの種類

| 列 | LC | HH | LP | SD | HT | BD | LT | FT | CY |
|---|---|---|---|---|---|---|---|---|---|
| チャンネル | 1A | 11 / 18 | 1B / 1C | 12 | 14 | 13 | 15 | 17 | 16 / 19 |

- 2 種類ある列(HH 閉 / 開、LP / LBD、CY / RD)は「今の種類」を持つ。初めはその列でいちばん多いチャンネル。
  列名の帯を押す・タッチのツールバーで切り替える。Alt を押しながらの操作はもう一方の種類
- ぶつかり: 同じセル(小節・tick)の同じチャンネル、または HHC と HHO。LP と LBD・CY と RD はぶつからず、同じセルに並べて
  描く(左右に半分ずつ)
- ペン(新しく置くチップの値 = #WAV の番号)はチャンネルごと。初めは(1)そのチャンネルでいちばん多い値 →(2)`#WAV` の
  ラベルかファイル名がチャンネルの言葉(`hhc|hh|hat|close` など)に合うもの →(3)同じ列のもう一方の種類のいちばん多い値 →
  (4)使っていない番号(音は合成音)。列名の帯の右クリック / 長押しで選ぶ。選択のモードでチップを 1 つだけ選ぶと、その列の
  ペンがそのチップの値になる(スポイト)
- 列を移したチップは、移った列の今の種類とそのペンの値になる(Alt で落とすと値はそのまま)。種類の切り替え(R)もペンの値に
  する(Shift+R・Alt+クリックの Shift で値はそのまま)。(変更) DTXC は番号を残すので、SD のチップを HT へ移すとスネアの音のまま
- ギター / ベース・BGM・SE などのチャンネルは編集しない(そのまま残る)。`#IF` の中の行は書き換えない(§8)

## 4. ペンのモード(既定)

押したところで何が起きるかは、置く前に影(枠)で見せる。

```
1. 列 col で、押した位置から遊び(チップの半分 + マウス 5 / タッチ 14 CSS px)以内の編集できるチップ → そのチップ(消す・動かす)
2. 吸着したセルが 999 小節より後ろ → 置けない
3. セルに、表示している分岐のチップでぶつかるものがある → 置けない
4. セルに同じチャンネルのチップ → そのチップ
5. セルにぶつかる別の種類(HHC↔HHO)→ 置き換える
6. それ以外 → 置く(LP/LBD・CY/RD の相方がいれば並べる)
```

| 操作 | マウス / ペン | タッチ |
|---|---|---|
| 置く | 空いたところを押す(押したときに音)。押したままドラッグすると同じ列に 1 ガイドごとに塗る(1 手)。4 px 動かすまでは塗らない。フリーでは 1 tick ごとに埋めず、指している所だけ | タップ(離したとき) |
| 消す | チップを押して離す。右クリック / 右ドラッグ(なぞった所を 1 手で) | チップをタップ(「元に戻す」付きのお知らせ) |
| 動かす | チップを押してドラッグ(Ctrl でガイドに合わせない、落とすとき Alt で値を残す) | 長押しで持ち上げてドラッグ |
| 種類 | Alt+クリック(チップなら切り替え、空きならもう一方の種類を置く) | 長押し → メニュー |
| 相方 | Shift+クリック(LP / CY の列で、もう一方の種類を横に置く) | 長押し → メニュー |
| メニュー | 小節番号の欄の右クリック | 空きの長押し・チップを長押しして離す・小節番号の欄の長押し |
| スクロール | ホイール・右のバー | 1 本指のドラッグ(慣性つき。チップの上から始めても) |
| 拡大 | Ctrl+ホイール・− ＋ | 2 本指 |

- ペンで書くと選択は外れる(書くたびに枠が付かないように)。選択のモードで選んだものはペンに戻しても残り、R・Delete が効く
- Apple Pencil(`pointerType: 'pen'`)はマウスと同じ。ペンを使っている間とその後 1 秒は、指のタップを無視する(手のひら)。
  マウス / ペンで操作している途中は、指の身振り(スクロール・長押し・取り消し)がそれを横取りしない
- メニューの外を押して閉じたときは、その押しで書かない
- 画面の上下の端 40 CSS px でドラッグすると自動でスクロールする(押しただけの手ぶれでは始めない)

## 5. 選択のモード(DTXC の選択モード)

| 操作 | マウス / ペン | タッチ |
|---|---|---|
| 選ぶ | チップ / BPM の印を押す(Shift で足す、Ctrl / ⌘ で入れ替え)。選んでいたものを押して離すとそれだけにする | タップで選ぶ / 外す |
| 範囲で選ぶ | 何もないところからドラッグ(Shift / Ctrl で今の選択に足す)。枠が掛かる列と、広い配置では BPM レーン。チップは中心が枠から半分の高さまで出ていても入る。`#IF` の中は入らない | 何もないところを長押ししてからドラッグ |
| 外す | 何もないところをクリック・Esc | 何もないところをタップ |
| 動かす | 選んだものの上からドラッグ。つかんだものをガイドに合わせ、ほかは同じだけ。BPM の印は縦だけ | 選んだチップの上からドラッグ(ほかはスクロール) |
| メニュー | 右クリック(選んでいないチップの上なら、先にそれだけを選ぶ) | 長押し(動かさずに離す) |

- 動かす・貼る・複製で行き先にあったぶつかるチップは消える(動かしたものが勝つ。消えた数をお知らせ)。動かすもの同士が
  同じセルに来たら、元の位置が行き先にいちばん近いものを残す。行き先に表示している分岐のチップがぶつかれば、移動ごとやめる。
  はみ出すときはブロックごと寄せる(リードインより前・999 小節の最後の tick より後ろ・列の外へ出さない)。(変更) DTXC は
  出られないチップだけ置いていく
- ↑↓ は選んだものを 1 ガイド(Alt で 1 tick)動かす(値はそのまま。続けて押すと 1 秒の間は 1 手)。←→ は隣の列へ
- ボーナスの印(0x4C〜0x4F、値はレーン + 1)はチップについて動き、チップと一緒に消える。ボーナスのチップを置き換えたチップは
  ボーナスを引き継がない。CY↔RD に切り替えると印の値も替える

### 5.1 クリップボード

- コピーは選んだもののいちばん前からの u の差で持つ。BPM の印は BPM の値で持つ。(変更) DTXC は `#BPMzz` の番号で貼るので、
  別の譜面では別のテンポになる
- クリップボードはページの中で 1 つ(別の譜面にも貼れる。DTXC と同じ)。切り取り = コピーして消す(1 手)
- 貼る位置(ガイドに合わせる): メニューから → メニューを開いたセル、キーから → マウスで指しているセル(レーンの上なら)、
  無ければ再生位置。(変更) DTXC はメニューの左上の位置。列とチャンネルはそのまま。貼ったものを選ぶ
- 複製(Ctrl+D。本アプリの追加): 選んだ小節の数だけ後ろの小節へ、小節の中の tick のまま写す(小節長が違っても拍の頭が揃う)

### 5.2 メニュー

```
切り取り / コピー / 貼り付け / 削除 / 後ろの小節に複製
──
すべて選択 / レーン内をすべて選択 [SD] / 小節内をすべて選択 [012]
──
種類を切り替え (R) / (LP・CY のチップを 1 つ選んでいれば){種類} も置く
──
ここに BPM… / 小節長… / 小節の挿入 / 小節の削除
──
ここから再生 / ここからテストプレイ / この小節を繰り返し再生(選んでいれば、選んだ小節)
```

切り取り・コピー・削除・複製・種類は選択が要る。貼り付けはクリップボードが要る。↑↓ で動き、Enter で決める
(Space は BD のキーなので押さない)。小節番号の欄のメニューは小節の操作と再生だけ。

## 6. BPM

- 広い配置の BPM レーンを押す: 印の上ならその BPM を変える / 消す、空きならガイドに合わせたセルに新しい BPM。
  ペンのモードで印を右クリックすると消す。狭い配置ではメニューの「ここに BPM…」(そこに印があればそれを変える)。
  選んでいる印が 1 つだけなら Enter で変える
- ダイアログ: 0.0001〜1000、小数 4 桁まで(DTXC の数値入力と同じ範囲)。初めの値はそこの今の BPM。範囲の外では閉じない
- 書き方:
  1. 小節 000 の頭で印が無ければ、「曲の BPM (#BPM) を変える」(既定で入)で `#BPM` を書き換える(#BASEBPM は引かない)
  2. それ以外は印の値 = BPM − #BASEBPM(無ければ 0)。0 以下なら断る
  3. そこにあった ch 03 の印を変えるとき、値が 1〜255 の整数なら ch 03 のまま(16 進 2 桁)。ほかは ch 08。
     (変更) DTXC は読むときに ch 03 をすべて ch 08 に替える(差分を小さくするため替えない)
  4. ch 08 の番号: 同じ値の `#BPMzz`(`#IF` の外で 1 回だけ定義されたもの。値は書いた文字列で比べる)があれば使い回す。
     無ければ 01〜ZZ の空きのいちばん小さい番号(`#IF` の中の定義も避ける)を `#BPM…` の最後の行の後ろ(最初のデータ行より前)に足す。
     空きが無ければ断る
  5. 書き出すとき、この編集で足して使われなくなった `#BPMzz` の行を消す(元の譜面にあった定義は消さない)
- BPM を変えてもチップは動かない(u が同じ。時間だけ変わる)

## 7. 小節

### 7.1 小節長

小節番号の欄・メニューの「小節長…」。拍子(4/4・3/4・2/4・5/4・6/8・7/8・12/8)か倍率(0.01〜16、小数 6 桁まで)。

- 範囲: この小節だけ(既定。DTXC の「後続」なし)/ ここから(次に小節長を書いた小節の前まで。DTX の小節長の続き方そのもの)
- チップ: 拍の位置を保つ(既定。DTXC と同じ。`tick' = round(tick × L旧 / L新)`、どのチャンネルも。384 以上になるものは消え、
  消える数を OK の前に出す)/ 小節に合わせて伸縮(tick はそのまま。本アプリの追加)
- ch 02 の行は「前の小節と同じなら書かない、違えば書く(同じ値の行が元からあれば残す)」で直す。この小節だけのときは
  次の小節に元の長さを書き戻す
- `#IF` の中の ch 02 が関わる、または拍を保つのに `#IF` の中の行を動かすことになるときは変えない
- 1 手。(変更) DTXC は小節ごとに 1 手

### 7.2 小節の挿入 / 削除

- 挿入: 押した小節の前に空の小節を挿し、押した小節から後ろが 1 つ後ろへ(`#IF` の中の行も)。新しい小節の長さは押した小節と同じ、
  押した小節の頭の BPM の印も写す。(変更) DTXC は長さ 1・テンポ無し(3/4 やテンポの変わった所に挿すと拍子とテンポが変わる)
- 削除: 小節を消して詰める。消えるものがあれば種類ごとの数(ドラム・BGM・BPM の変化・そのほか・分岐の中の行)を見せて確かめる。
  BGM の開始チップがあればそう書く。小節の中の最後の BPM の変化は、次の小節の頭に印が無ければそこへ移す。後ろの小節の長さも
  保つ。(変更) DTXC は消した小節のテンポと長さの影響が後ろに出て、元に戻すと長さが戻らない
- 999 小節を超えるとき、`#IF` の中に小節長の行があるとき(表示している分岐の長さを `#IF` の外に書いてしまうため)は断る。
  演奏画面から持ってきたループの位置もずらす(元に戻すと戻る)

## 8. `#RANDOM` / `#IF`

- `#IF` の中の行は読むだけ(書き換えない・動かさない。新しい行は `#IF` の中に入れない)。表示する分岐は、演奏から来たときは
  その演奏の乱数、無ければ下書きのとき、無ければ分岐 1。表示している分岐のチップは斜線で描き、その位置には置けない
- 小節の挿入 / 削除だけは `#IF` の中の行の小節番号も動かす

## 9. 再生とテストプレイ

- ▶ / P: 再生位置から全部 AUTO で鳴らし、再生位置を追う(スクロールすると追うのをやめる。⇩ で戻る)。止めると止めた位置に
  とどまる。(変更) 演奏画面の停止は開始位置へ戻る。Shift+P は先頭(リードイン)から
- メトロノーム(M)・ドラムの音・再生速度 x0.5〜x1.5 は ⋯ から。トレーニングの設定には触れない(`EditorPlayer` は自分の設定を持つ)
- 「この小節を繰り返し再生」: その小節(選んでいれば選んだ小節の範囲)を繰り返す。折り返すと演奏画面のループと同じく 1 小節前から
- 再生中に書き換えると、次の再生から反映(お知らせ)。新しい番号の音はあとから読む
- 置いたときに音を鳴らす(⋯ の「置いたチップの音を鳴らす」。DTXC と同じく既定で入)。音が無ければ列の合成音。電子ドラム・キーで
  叩くと、その列のペンの音を鳴らし列を光らせる(書きはしない)

## 10. 保存

### 10.1 書き方(`DtxDoc`)

- 変えた(小節, チャンネル)の組の行だけを書き直す。触っていない行は元のバイト列のまま。書き直した組は元の最初の行の場所に、
  新しい組はチャンネルの並びの近くに入れる(`#IF` の中には入れない)
- チップの行は `#MMMCC: data`(小節 3 桁、チャンネルは大文字 16 進、data は空白なし)。分割数は全部のチップが割り切れる最小の数。
  同じ tick に同じチャンネルのチップが 2 つあれば行を分ける。小節長は小数 6 桁まで、BPM は 4 桁まで(`.`、指数なし)
- 文字コードと改行は元のまま。書き直した行が Shift-JIS で書けなければ全体を UTF-8(BOM 付き)にする(NX は BOM で見分ける。
  vid2dtx は読めないのでお知らせ)。書き直した文書は改行で終える(DTXC は改行の無い最終行を読み落とす)
- ⋯ の「文字コード」で、元のまま / Shift-JIS / UTF-8(BOM 付き)を選べる。Shift-JIS で書けない文字があれば変えない
- 編集の印になるものは足さない。(変更) DTXC は `#DTXC_CHIPPALETTE` などを書く

### 10.2 渡し方

- 保存(Ctrl+S): .dtx をダウンロード。「名前を付けて保存…」(Ctrl+Shift+S。Chromium だけ)で選んだファイルがあれば、
  以後の保存はそこへ上書き(上書きできなければダウンロードにして、そう知らせる)
- 共有…(iPad / スマホ): AirDrop・ファイル App など
- 曲フォルダを ZIP で保存 / 曲パックを ZIP で保存: 元の ZIP の中身は圧縮したまま写し、編集した譜面だけを入れ替える
  (名前は `<元の名前>_edited.zip`)。曲パック全体のときは「前回の ZIP」にも残す。フォルダから読んだ曲パックは全部の
  ファイルを読み直す(お知らせ)
- 下書き: 編集は書き換えて 1.5 秒後・閉じたとき・タブを隠したときに IndexedDB に書く(新しいものから 30 件まで)。次に同じ譜面を開くと
  続きを開くか聞き、曲パックを開いたときにも戻すか聞く

## 11. vid2dtx の確信度

`<譜面>.dtx.conf.json`(vid2dtx が書く `{chips: [{m, tick, ch, conf, why?}]}`)があれば、確信度 0.7 未満のチップに枠を付ける
(0.4 未満は赤、ほかは橙)。「次の要確認」(ツールバー)/ N で確信度の低い順(同じなら前から)に回り、最後まで行ったら最初へ。
回ったチップを再生位置に置き、選ぶ(R・Delete ですぐ直せる)。理由(`why`)をお知らせに出す。動かしたチップは枠が外れる
(vid2dtx と同じく (小節, tick, チャンネル) で引くため)。ファイルは書き換えない(ZIP にはそのまま入る)。⋯ の「確信度を表示」で隠せる。

## 12. キー

演奏中の `RESERVED_CODES` とは別。Space は BD の既定のキーなので何もしない(スクロールもボタンの決定もしない)。F1 も何もしない。
文字は `e.code`(配列・IME に左右されない)、記号は `e.key`(JIS 配列の [ ] も印字どおり。IME が入力中の 'Process' だけ e.code)。
入力欄・ダイアログ・メニューが開いている間は、それぞれのキー(Enter = 決定、Esc = 取り消し)だけ。

| キー | 動作 | 手本 |
|---|---|---|
| Ctrl/⌘+Z、Ctrl/⌘+Shift+Z・Ctrl+Y | 元に戻す / やり直す | DTXC・V2D |
| Ctrl/⌘+S、Ctrl/⌘+Shift+S | 保存 / 名前を付けて保存 | DTXC・V2D / 追加 |
| Ctrl/⌘+X / C / V / D / A | 切り取り / コピー / 貼り付け / 複製 / すべて選択 | DTXC(D は追加) |
| E / S | ペン / 選択 | (変更) DTXC の Ctrl+Space は IME の切り替え |
| P / Shift+P | 再生・停止 / 先頭から | (変更) DTXC の F6 / F5 はブラウザのキー |
| T | テストプレイ | 追加 |
| M | メトロノーム | 追加 |
| R / Shift+R | 種類の切り替え(選んだもの、無ければ指しているチップ)/ 値を残す | DTXC の表裏反転 |
| N | 次の要確認 | V2D の n |
| [ / ] | ガイドを粗く / 細かく | (変更) DTXC の F3 / F4 |
| − / ＋ | 縮小 / 拡大(再生位置を中心に) | 追加 |
| PageUp / PageDown | 1 小節先 / 前(小節の頭に揃える) | DTXC |
| Home / End | 先頭 / 最後のデータの次の小節 | 追加 |
| ↑ / ↓ | 選んでいれば 1 ガイド動かす(Alt で 1 tick)、無ければ再生位置を 1 ガイド | 追加 |
| ← / → | 選んだチップを隣の列へ | 追加 |
| Delete / Backspace | 選んだものを消す | DTXC |
| Enter | (BPM の印を 1 つ選んでいれば)BPM を変える | — |
| Esc | ドラッグの取り消し → メニュー・ダイアログを閉じる → 選択を外す。画面からは出ない | (変更) |
| ? | ショートカットの一覧 | (変更) DTXC の F1 |

## 13. 手本との違い

| 挙動 | DTXC | V2D | 本アプリ | 理由 |
|---|---|---|---|---|
| 縦の軸 | 小節 192 等分・拍に比例 | 時間(560 px/秒) | u(4/4 の小節 = 1)、384 tick、拡大 0.25〜5.6 | (変更 vs V2D) BPM を変えても並びが崩れない |
| レーン | 13 以上の別々のレーン | 9 列 | 9 列 + 種類 + 左右に並べる相方 | (変更) 演奏画面と同じ絵 |
| 吸着 | 切り捨て | いちばん近い | いちばん近い、小節長に合わせた拍 | (変更 vs DTXC) チップの中心が押した所に来る |
| 埋まったセル | レーンごとに置き換え | チャンネルごとに何もしない | チャンネルごと、HH だけ排他。チップを押すと消す | (変更) |
| モード | 編集 / 選択 | なし | ペン / 選択 | (変更) 1 つの身振りで直せる |
| 新しいチップの値 | レーンの割り当て / 一覧の行 | 列ごとのいちばん多い (ch, id) | チャンネルごとのペン(多い値 → 名前 → 相方 → 空き番号) | (変更 / 追加) |
| 列をまたぐ移動 | チャンネルと値の扱いが崩れる(§11 Q4・Q13) | — | 移った列の今の種類とそのペン、Alt で値を残す | (変更) |
| 種類の切り替え | 番号を残す | — | ペンの値にする | (変更) |
| 元に戻す | 保存した点を持たない、選択も記録、不具合多数(Q4〜Q9) | 戻すだけ、変更の印が不正確 | 文書の写しで戻す、やり直しあり、保存した点が正確 | (変更) |
| BPM の番号 | 浮動小数の == で比べ、解放しない、1296 で落ちる(Q10) | — | 書いた文字列で使い回し、`#IF` を避けて割り当て、使わなくなった新しい定義は書き出すとき消す | (変更) |
| 小節長 | 小節ごとに 1 手、はみ出しを黙って消す | — | 1 手、消える数を先に見せる、伸縮も選べる、`#IF` なら断る | (変更 / 追加) |
| 小節の挿入 | 長さ 1、テンポ無し | — | 押した小節の長さと頭のテンポの写し | (変更) |
| 小節の削除 | 元に戻すと長さが戻らない(Q5) | — | 長さと BPM を持ち越す、種類ごとの数を見せて確かめる | (変更) |
| 保存 | 全体を書き直す、cp932、`#IF` を平らにする | ドラムの行を作り直す、cp932 CRLF、.bak | 変えた組だけ、元の文字コードと改行、書けなければ UTF-8 BOM、ダウンロード / 共有 / ZIP / 上書き | (変更) |
| `#RANDOM` | 全部の分岐を平らにする | 見ない | 読むだけ、表示は演奏した分岐か分岐 1 | (追加) |
| 再生 | 外部のビューアを起動、`#DTXVPLAYSPEED` を書く | 前もって混ぜた音 | `EditorPlayer`、止めた位置にとどまる、自分の設定 | (追加 / 変更) |
| テストプレイ | ビューアの起動 | — | 本物の演奏画面、止めた位置へ戻る | (追加) |
| 自動保存 | なし | なし | IndexedDB の下書き | (追加) |
| ショートカット | F3〜F7・Ctrl+Space・F1 | n | [ ]・P・T・?・N。Space と F キーは使わない | (変更) ブラウザ・IME・BD の決まり |
| 貼る位置 | メニューの左上 | — | メニューを開いたセル / 指しているセル / 再生位置 | (変更) §11 Q15 |
| 複製・小節のループ・確信度の枠 | なし | 確信度の枠(V2D) | Ctrl+D・繰り返し再生・vid2dtx の枠と巡回 | (追加) |

## 14. まだ無いもの

- 横のパネル(チップ / 小節のタブ)、譜面の情報(#TITLE など)・音源(#WAV)の編集、叩いて入力・録音、フォルダへの上書き保存、
  新しい難易度の作成(設計の P3)
- ギター / ベースのチップの編集、検索 / 置換(DTXC の Ctrl+F / Ctrl+H)
- 999 小節より後ろ(NX は Z99 まで読めるが、本アプリのパーサは 3 桁の 10 進まで)
- 書き直した行の行末のコメントは消える(DTXC も同じ)
