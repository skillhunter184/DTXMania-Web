# guitar-bass

ギター / ベース(GR)の演奏の仕様の入口。元実装(DTXManiaNX と、それを移植した DTXManiaAI の GR モード)から抽出した挙動は
話題ごとのファイルに分けてある(英語。行番号付きで、各ファイルの [FIX] / [ADD] は抽出のあと別の担当がコードで裏取りして直したところ)。
このファイルは、それを本アプリ(1 人で練習する Web アプリ)へ持ち込むときに決めたことの一覧。

| ファイル | 中身 |
|---|---|
| [gb-chart.md](gb-chart.md) | チャンネル → 押さえ方のビット(R=4 G=2 B=1 Y=16 P=32、OPEN=0)、ウェイリング・ロングノート・空ピック音・ウェイリング音のチャンネル、ロングノートの対付け、楽器の有無の判定、譜面の外の楽器の自動発音 |
| [gb-judge.md](gb-judge.md) | 入力(ネックは押している間、ピック・ウェイリングは押した瞬間)、ピックで狙うチップ(過去優先)、押さえ方の照合、空ピックと BAD(Light)、AUTO ピック、取り逃し、ウェイリング、ロングノート、音(1 パート 1 音)、1 フレームの処理の順 |
| [gb-score.md](gb-score.md) | XG のスコア式(全 Perfect の補正・ロングノート・ウェイリング・フルコンボの加点)、AUTO の補正(スコアと達成率で別の式)、ゲージ(ギター / ベースの列)、コンボ、達成率・ランク・フルコンボの定義、トレーニングのループでの戻し方 |
| [gb-screen.md](gb-screen.md) | NX のギター画面の座標(720p と 1080p)、スクロールの速さ(ドラムの半分)、チップ・OPEN・ロングノートの帯・ウェイリングチップの描き方、レーンフラッシュ・チップファイア・ウェイリングの光の柱・判定文字・コンボ、本アプリの 1920×1080 への当てはめの案 |
| [gb-config.md](gb-config.md) | 既定のキー、AUTO の旗とプリセット、オプション(リバース・Light・LEFT・RANDOM など)、ドラム / GR の切り替え、FLIP、楽器別ファイルの曲のまとめ(SongInstrumentMerge)、DTXManiaAI がギターのトレーニングを作らなかった理由、音量 |

譜面の読み込みのうち DTXManiaAI と同じところは [dtx-audio.md](dtx-audio.md) の §7.3〜§7.6・§9.3・§12.4 にもある。

## 本アプリで決めたこと

元実装と違えたところは、コードのコメントにも「(変更)」として理由を書いてある。

### 画面と遊び方

| 項目 | NX | DTXManiaAI | 本アプリ | 理由 |
|---|---|---|---|---|
| 弾くパート | ギター(左)とベース(右)を 1 画面に並べ、2 人で弾く | 同じ(ベースは既定で全 AUTO) | **1 パートだけ**。曲の一覧の「ギター」「ベース」の行で選ぶ | 1 人で練習するアプリなので。画面の右側はトレーニングメニューが使う |
| 弾かないパートとドラム | ドラムはバーの通過で音だけ鳴らす | 同じ | ドラムともう一方のパートを**伴奏**として音だけ鳴らす(BGM と同じバス・AUTO の音量) | NX と同じ(もう一方のパートは NX でいえば全 AUTO の側) |
| ドラムの演奏でのギター / ベースのチップ | バーの通過で音だけ鳴らす | 同じ | 同じ(伴奏)。**以前の本アプリは鳴らしていなかった** | ギター入りの譜面でギターの音が欠けていた |
| 楽器の選び方 | Config の Drums / Guitar と、選曲画面の FLIP(Y×2) | 同じ + 決定後の難易度選択 | 曲の一覧に楽器ごとの行を出し、押した行の楽器を弾く。1 つの譜面にギターとベースがあれば両方の行に出る | マウス / タッチの一覧なので |
| 楽器別ファイルの曲(`dm_*` / `gt_*` / `ba_*` と set.def の 3 ブロック) | 別々の項目 | 1 項目にまとめる(SongInstrumentMerge) | DTXManiaAI と同じ規則でまとめる(`js/core/instmerge.js`) | 同じ曲が 3 つ並ばないように |
| 判定ラインの位置 | 画面上(Y 154 @720p)。チップは下から上へ。リバースで画面下 | 同じ | 同じ。リバースはトレーニングメニューの「リバース」 | NX と同じ |
| 5 レーンと 3 レーン | いつも 5 レーンの配置(3 レーンの譜面は Y / P が空く) | 同じ | 同じ | |
| ハイスピード | `(raw+1)×0.5`、ギターはドラムの半分の px/ms | 約 2.5 倍速い(ドラムで直したのと同じ誤り) | NX と同じ式。トレーニングのハイスピードはドラムと別に持ち、**既定は x2.0** | NX の既定 x1.0 はギターだと判定ラインまで約 5.8 秒かかり、ドラムの既定(約 3.6 秒)よりずっと遅い |
| 判定タイミング調整 | 楽器ごと(InputAdjustTimeGuitar / Bass) | 同じ | **ドラムと別に持つ**(トレーニングの「判定タイミング調整」を、ギター / ベースの演奏中はこちらの値として動かす)。ギターとベースは 1 つを共有。ドラムと共有していた頃の保存は、その値をギター / ベースにも引き継ぐ | NX・DTXManiaAI とも楽器ごと。同じキーボードでも、叩き方の違う楽器ではずれ方が違う。ギターとベースは同じキーで弾くので 1 つ(ハイスピード・リバースと同じ) |
| LEFT | ボタンを描く列を左右反転(R G B Y P → P Y B G R)。チップ・ロングノート・レーンフラッシュ・弦・チップファイア・上のボタン列(絵の LEFT 用の行)。OPEN・ウェイリング・小節線・パネル(ウェイリングの列)・判定ライン・下の枠・判定文字はそのまま。キー・判定・AUTO はボタンのまま(表示だけ)。既定 OFF | 項目なし(常に OFF) | NX と同じ。トレーニングメニューの「LEFT(左利き)」(ギターとベースで共有、既定 OFF)。ボタン列はスキンに LEFT 用の行が無いので、画像のレーン 5 列を入れ替えて作る(裏返すと文字が鏡文字になる)。下の枠は、本アプリでピックのときにボタンの色のポールピースを光らせるので、ポールピースの所(ボタンの中心 ± 14)だけ入れ替える。タッチは見えている列のボタン。キーはボタンのまま(NX と同じ)なので、設定に**左利き用の並び**(R〜P = ; L K J H、PICK = F・D、WAIL = S。既定をキーボードの中央で鏡に映したもの)を押せば入るボタンを置く | 左手でピックする人のため。キーを LEFT に連動させると、ボタン名で並ぶ割り当ての欄と食い違う |
| 未対応のオプション | RANDOM 系・SUDDEN / HIDDEN・Specialist・シャッター・判定ラインの位置・演奏中のハイスピード変更キー | 同じく未対応 | 未対応 | |
| GDA / G2D(ギター専用の形式) | 読める | 読めない | 読めない | |
| ゲームパッド(ギターコントローラ) | DirectInput。ボタン・X/Y/Z 軸の向き(\|値\| > 500/1000)・POV の 8 方向をどれも押す / 離すにする。ピック・ウェイリングは押した瞬間で入力ごとの時刻、ネックは押している間。割り当ては機器の ID 付き(gb-config.md §1.5) | Gamepad.current の名前付きボタン 16 個だけ(軸・ハットは不可)。時刻はフレーム。ギター用の割り当て画面は無い | **Gamepad API**。設定の「ギターコントローラ(ゲームパッド)」で R G B Y P / PICK / WAIL / START に割り当てる(押して追加。キーと同じ規則で 1 行 12 個・取り上げ・元に戻す)。ボタン・軸の向き(0.5 で押し、0.35 で離す)・ハットの上下左右(斜めは両方)。4 ms ごとに読み(ゲームパッドが無い間は 250 ms)、時刻は `gamepad.timestamp`。同じ取得の中はネック → PICK → WAIL の順。1 つの割り当てを全部のゲームパッドに使う。既定は Xbox 360 の Guitar Hero / Rock Band ギター(XInput)の配置(実機では未確認) | ブラウザはゲームパッドの変化を知らせないので読みに行く(Chrome / Firefox が機器を読む間隔が 4 ms)。ハットは Chrome / Firefox が軸 1 本に載せ、中央を範囲外の値にする。戻りの 0.35 は Rock Band のチルトのちらつきで連打にしないため。機器ごとの割り当ては、同じ機器でもブラウザで名前が違う(Chrome と Firefox)ので持たない。START は本アプリの追加(ギターを持ったまま始める)。押したままのボタン(PS2 のギターの十字キーなど)は押して追加で数えない。Safari はハットが読めず時刻が秒なので、読んだ時刻を使う |

### 入力と判定

| 項目 | NX | DTXManiaAI | 本アプリ | 理由 |
|---|---|---|---|---|
| 既定のキー | ギター R〜P = F1〜F5 / Pick = `:`(と `]`)/ Wail = 右 Ctrl。ベースはテンキー | NX と同じ | **R G B Y P = A S D F G / PICK = J・K / WAIL = L**。ギターとベースで共有し、ドラムの割り当てとは別に持つ | ブラウザでは F1 が AUTO 切替、F5 が再読み込み、Ctrl は割り当て不可。左手でネック、右手で J・K を交互に押してピック |
| ピックの時刻 | 入力イベントの時刻 | フレームの時刻(1 フレーム 1 ピック) | 入力イベントの時刻(ドラムと同じ。押した時刻までのフレームの処理を先に済ませる) | |
| 押さえ方を読む時刻 | フレームの処理の時刻(60 fps なら同じフレームの 16.7 ms 以内の押下を拾う) | フレームの時刻 | ピックの瞬間。合わなければ **30 ms(タッチは 50 ms)待ち**、その間にボタンが合えばピックの時刻で判定する。時間切れなら空ピック。待っている間はそのチップを取り逃しにしない。締め切りより後の時刻の押下はそのピックに数えない(重いフレームで入力がまとめて届いても同じ結果) | 打鍵ごとに時刻を持つので、NX の「同じフレーム」の代わりの猶予。画面の Hz や処理落ちで判定が変わらない |
| 押さえ方の照合 | AUTO でないボタンがチップとちょうど同じ(押さえすぎも外れ)。OPEN は何も押さえない | 同じ | 同じ | |
| AUTO ピック中のピック | 受け付ける(早いピックで先に当たることがある。コメントは古い) | 無視 | 無視 | ボタンだけを練習するための設定なので |
| AUTO ピックの時刻 | 画素の切り捨てで約 11 ms 遅れる | 時刻ちょうど | 時刻ちょうど | |
| AUTO ピックの判定 | AUTO でないチップは判定タイミング調整のずれで判定 | いつも Perfect | NX と同じ | |
| 空ピックの BAD(Light) | Light 既定 ON(BAD なし) | 同じ | 同じ。設定の「空ピックでコンボを切る(BAD)」か、トレーニングメニューの「空ピックで BAD」(同じ値)で OFF にできる。演奏中に切り替えると次のピックから効く | 練習の途中で厳しさを変えられるように |
| AUTO のプリセット | 選曲画面のクイック設定の Auto Mode(All Auto `AAAAAAA` / Auto Neck `AAAAA__` / Auto Pick `_____A_` / Custom / OFF)。今の組み合わせから選択を推定するが、ギターの OFF は G を、ベースは G・Y・P を見落とす | CONFIG の OFF / AUTO NECK / AUTO PICK / ALL AUTO。PICK でウェイリングも AUTO にする。カスタムが無く、回すと上書きする | トレーニングメニューの「AUTO プリセット」。当てる組み合わせと推定は NX のとおり(すべて・ネック・ピックは WAIL を見ず、OFF は WAIL も手動)で、見落としは直す。←→ で OFF → ネック → ピック → すべて と回す。どれにも当たらない組み合わせは「カスタム」と出し、プリセットへ回したときに覚えておいて、回して戻れば元に戻す(覚えるのはその演奏画面の間だけ) | 練習中にネックだけ / ピックだけの AUTO へすぐ切り替えられるように。細かい組み合わせは今までどおり自動演奏詳細で |
| BAD の表示 | 何も描かない | MISS で代用 | 「BAD」の文字(Miss の色) | 何が起きたか分かるように |
| ロングノートを離したとき | 音を止めるつもりのコードが番号を取り違えていて止まらない | 止める | 止める | |
| ウェイリングの予約 | 2 回のピックで同じチップを 2 度積み、1 回で 2 度加点する | 1 度だけ | 1 度だけ | |
| ウェイリング音 | 0x2F のチップ(ギターだけ)、無ければスキンの歓声 | いつも鳴らす | 0x2F のチップだけ。ベースは鳴らさない(歓声の音を持っていない) | |
| ウェイリングチップの表示 | 成立したら消える。成立しなかったものは判定位置を 234 px(720p)過ぎるまで描く | 予約の締め切り(1 秒)で消す | 成立したら消え、成立しなかったものは見える範囲から流れ出るまで描く。予約の締め切りは DTXManiaAI と同じ 1 秒 | ハイスピードが遅いと 1 秒では画面の途中で消えるので |
| 全部 AUTO(F1 の自動演奏) | AUTO チップとして数える(スコア 0) | — | ドラムの自動演奏と同じく、手動の Perfect と同じに数えるデモ | アプリの中で F1 の意味をそろえる。ボタン別の AUTO は NX のとおり |
| タッチ | — | — | レーンを押す = そのボタンを押さえてピック、離すまで押さえたまま。レーンの外を押す = 何も押さえずにピック(OPEN)。続けて(50 ms 以内に)置いた指は同じピックの押さえ方に足す。待っている間に離した指は押さえ方から引かない | 本アプリの追加。違うレーンを素早く叩いて離したのが OPEN に当たらないように。ウェイリングはタッチでは出せない |
| 電子ドラム(MIDI) | — | — | ギター / ベースの演奏では使わない | |

### 成績

| 項目 | NX | DTXManiaAI | 本アプリ | 理由 |
|---|---|---|---|---|
| スコア | XG の式。足すたびに端数を持つ。0 未満にも 9,999,999 超にもなる | int で切り捨て・0〜9,999,999 | NX と同じく端数を持ち、**足すたびに 0〜9,999,999 に収める** | ドラムの実装と同じ。NX はチップ 25 個未満の譜面でスコアが負になる |
| 全 Perfect の補正(チップ 50 個未満) | 補正にもコンボ数を掛ける(1,000,000 にならない) | 掛けない | 掛けない | ドラムの実装と同じ |
| 全 Perfect の補正に使う Perfect 数 | AUTO 込みの数(ループの折り返しで戻さない) | — | AUTO 込みの、この回(リセット・ループの折り返し・数え直しの後)の数 | NX のままだと、トレーニングの 2 周目以降はフルコンボなら Perfect でなくても 1,000,000 になる(NX はトレーニングでスコアを出さないので見えない) |
| フルコンボの加点 | 演奏の終わりに +30000 / +15000(AUTO の補正なし) | 補正を掛ける | NX と同じ。曲を最後まで演奏し、その回(ループの折り返しや一時停止中のシークで数え直していない)で全部のチップを判定したときだけ | トレーニングでは途中から始めたり数え直したりできるので |
| ゲージ | ギター / ベースの列 [+0.006, +0.003, 0, −0.030, −0.050]、Miss に難易度の係数 | 同じ | 同じ | ドラムの XG の値とは違う |
| STAGE FAILED | どちらかのゲージが尽きたら(トレーニングでは無し) | あり | 無し | トレーニングのアプリなので(ドラムと同じ) |
| 早い / 遅い | AUTO でないチップだけ | AUTO も数える | NX と同じ | |
| 判定数の割合 | AUTO 抜きの数 / AUTO 込みの判定数 | 同じ | 同じ | |
| 達成率 | 手動の判定が 1 つも無いうちはコンボの項を 0 | 全 AUTO のときだけ 0 | NX と同じ | |
| ループの折り返し | AUTO 抜きの数・コンボ・スコア・早い / 遅いを戻す。AUTO 込みの数とゲージは残す。ロングノートの加点の合計と保持は曲内ジャンプで戻る | — | NX と同じ | |

### 音量

| 項目 | 本アプリ |
|---|---|
| 弾いているパートの音 | 「ギター / ベース音量」(設定。演奏中はメニューの「ギター音量」「ベース音量」)。ドラムの「ドラム音量」と同じ 'chip' のバス |
| 伴奏(ドラム・もう一方のパート) | 「BGM 音量」のバス。相対音量は NX の AutoChipVolume(80)に当たる 0.8 |
| AUTO ピックのチップ | AUTO の相対音量 0.8(NX のモニタ音量)。自動演奏(F1)は手動と同じ 1.0(ドラムの自動演奏と同じ) |
| 1 パート 1 音 | 同じパートの前の音を止めてから鳴らす(NX tPlaySound)。先読みで予約した音は、次の音の時刻で止める。押さえ続けたロングノートを離したときは、そのロングノートの音だけを止める |
